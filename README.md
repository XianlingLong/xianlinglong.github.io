# xianlinglong.github.io

Personal academic homepage of Xianling Long (Peking University), served by GitHub Pages at https://xianlinglong.github.io/

## How to edit
- All content is in `index.html` — edit it directly on github.com (pencil icon) and commit; the site updates in ~1 minute.
- To add a profile photo: upload a `photo.jpg` to this repository, then in `index.html` remove the `<!-- -->` around the `<img ...>` line near the top.
